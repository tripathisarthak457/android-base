---
name: agp-9-upgrade
description: Upgrades, or migrates, an Android project to use Android Gradle Plugin
  (AGP) version 9. Do not use this skill for migrating Kotlin Multiplatform (KMP)
  projects.
---

Google's `agp-9-upgrade` skill (Android skills v1.0.15, Apache-2.0) is vendored for the generated projects at `templates/android/.agents/skills/agp-9-upgrade/`.
Read `templates/android/.agents/skills/agp-9-upgrade/SKILL.md` and resolve every relative path in it from that folder.
When you change a template, also read the `agp-9-upgrade` row of the "Google's Android skills" table in that template's `AGENTS.md`:
it lists where the generated projects differ, and it wins wherever the two disagree.
