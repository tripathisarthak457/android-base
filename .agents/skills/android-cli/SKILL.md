Google's `android-cli` skill (Android skills v1.0.17, Apache-2.0) is vendored for the generated projects at `templates/android/.agents/skills/android-cli/`.
Read `templates/android/.agents/skills/android-cli/SKILL.md` and resolve every relative path in it from that folder.
When you change a template, also read the `android-cli` row of the "Google's Android skills" table in that template's `CLAUDE.md`:
it lists where the generated projects differ, and it wins wherever the two disagree.
