Google's `play-billing-library-version-upgrade` skill (Android skills v1.0.17, Apache-2.0) is vendored for the generated projects at `templates/android/.agents/skills/play-billing-library-version-upgrade/`.
Read `templates/android/.agents/skills/play-billing-library-version-upgrade/SKILL.md` and resolve every relative path in it from that folder.
When you change a template, also read the `play-billing-library-version-upgrade` row of the "Google's Android skills" table in that template's `CLAUDE.md`:
it lists where the generated projects differ, and it wins wherever the two disagree.
