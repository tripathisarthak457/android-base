# BaseApp

A SwiftUI app for iPhone and iPad, iOS 17 and later: `@Observable` stores, local Swift packages,
and an Xcode project generated by XcodeGen.

## Getting started

```bash
brew install xcodegen                 # once
xcodegen generate                     # writes BaseApp.xcodeproj from project.yml
open BaseApp.xcodeproj
```

The `.xcodeproj` is generated and ignored by git: change `project.yml`, then run `xcodegen
generate` again. Set your team in `project.yml` (`DEVELOPMENT_TEAM`) to run on a device.

## Building and testing from the command line

```bash
xcodegen generate
xcodebuild -project BaseApp.xcodeproj -scheme BaseApp \
  -destination 'platform=iOS Simulator,name=iPhone 17' build test
(cd Packages/Core && xcodebuild -scheme Core-Package -destination 'platform=iOS Simulator,name=iPhone 17' test)
(cd Packages/Features && xcodebuild -scheme Features-Package -destination 'platform=iOS Simulator,name=iPhone 17' test)
```

## Layout

```
project.yml               the Xcode project, as XcodeGen reads it
Config/                   Dev.xcconfig (Debug) and Prod.xcconfig (Release): API_BASE_URL
BaseApp/                  the app target: composition root, window, tabs, commands, privacy manifest
BaseAppTests/             app-level tests
Packages/Core/            AppCore, DesignSystem, Navigation, Networking, Persistence
Packages/Features/        per feature: <Name>Data (repository, DTOs) and <Name>Feature (views, stores)
```

A feature depends on its own data target and on Core. Data never depends on a feature, and
features never depend on each other.
