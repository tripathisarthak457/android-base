### 1.1 `templates/android/tools/perf/gates.toml` (staging)

Header rules (S:tools/perf/gates.toml:1-23):
- `perf.sh --gate <column>` compares the median of the runs with one column; non-zero exit on any failing row, including a row of that column the run did not measure (:1-2).
- Columns: `solid` (everything preset, solid chrome), `standard`, `lean`, `smoke` (tolerance against a `--baseline` reference run), `large` (Expanded width or more; a tablet or the phone with display overridden, which only the owner may agree to; an emulator's numbers are relative evidence, never a gate) (:4-8).
- A limit is a number (metric at or under it), `true` (a check that must pass every run) or `"ratchet"` (reported, not gated: first measured value plus 10 % goes here); a smoke tolerance is `reference + max(add, reference x scale)` (:10-12).
- What gates a release (REQUIREMENTS 42): for tab switches, push/pop, back gesture, Rapid Back: what the user feels, hitch time per second of motion, and janky frames after each motion's first (:14-16). A first frame from idle misses its deadline on this phone whatever is drawn (GPU clocked down: an empty-content build misses it on 7 of 7 switches), so it is reported, not gated (:16-17).
- Rows marked `[non-regression]` hold the worst run of the merge's acceptance plus its noise margin, never more than the limit they replaced where the merge met it; they may only go down, and each improvement is written back (:18-20).
- Measured on a Redmi Note 10 Pro (120 Hz, 8.33 ms budget), release builds compiled with their baseline profile; frame times are UI-thread ms; janky is the FrameTimeline count (:22-23).

### 2.1 `HO/WP02-M1.md:281-304` (MVI contract)
- [in-code] `handleEvent` never suspends; I/O only through `launchLatest` / `launchExclusive`; repository flows through `observe` (`HO/WP02-M1.md:283-286`). Code: `S:core/mvi/src/main/kotlin/com/base/app/core/mvi/MviViewModel.kt:33` (KDoc: slow work goes through `launchLatest` or `launchExclusive`).
- [lesson] Initial loads come from an `Appeared` event that the route sends from `LaunchedEffect(Unit)`, guarded with `if (current.loadState == LoadState.Idle)` because the entry can be recomposed (`HO/WP02-M1.md:284-286`). (WP04 and WP02-M3 later say a screen's first composition must be final and seeded from `peek`; see 2.4 and 2.14.)
