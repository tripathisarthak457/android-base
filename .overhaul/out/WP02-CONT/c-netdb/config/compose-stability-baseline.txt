# Composable parameters the Compose compiler compares by identity, accepted with a reason:
# `fqName(parameter)  # why it has to stay`. Deleting a line records a fix; the check fails
# again if the parameter comes back.
io.example.fitcnetdb.core.designsystem.component.list.AppSwipeToAction(resetKey)  # any value whose change closes the row; callers pass the row's own key
io.example.fitcnetdb.core.navigation.back.BackHandlerEffect(handler)  # added to and removed from the dispatcher by identity, so identity is the comparison it needs; every caller remembers its handler
io.example.fitcnetdb.core.navigation.stack.rememberEntryLifecycle(key)  # returns a value, so it is never skipped; the key is only an effect key, which effects compare with equals
