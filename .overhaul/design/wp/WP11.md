# WP11 PeriFlow fixes (separate repository, local branch, never pushed)

Wave 3: after WP04 (shell), WP05 (glass) and WP06 (the devtools fix) have merged into the generator, so their code is
ported rather than written twice, and after checkpoint 2 has fixed the glass variant. Kotlin/Compose, Gradle (medium),
the phone (heavy). Lock budget: Gradle about 2 h, adb about 3 h. PeriFlow's Gradle JVM arguments differ from the
template's, so run `./gradlew --stop` under the lock whenever you pause (Part D 14). Repository: `D:/projects/jorwen/periflow`
(a monorepo; only `periflow-android/` is in scope). The user asked for the fixes on a local branch, committed, not pushed.

## Why

PeriFlow is the hand-improved app whose glass the user likes but whose frame rate drops: on the Redmi, scrolling Today
is 6.8 % janky with GPU p90 20 ms; tab switches 4.0 %; push/pop 6.1–6.5 % with p99 up to 77 ms; PSS 108 MB
(device-baseline §0, F15). Root causes are known and measured (periflow-learnings §3.4–3.5, G1–G17, §4.2 N1–N11): the
bar re-renders for half a second on every tap, it is destroyed and rebuilt (with its AGSL shaders) on every return to
a root, three full-window background fills, a CPU-painted aura, an orb that keeps the frame loop alive, fades over
live backdrops, a second composed tab row, no quality tiers, a double pop on rapid Back during a sheet dismiss, a
sheet that re-measures every frame, a static inset local that recomposes whole screens, Back swallowed for half a
second after every push. It also ships the template's undraggable devtools badge and the Play update restart.

## Steps

1. **Baseline**: add the A3.8 resource-id tags to PeriFlow (`testTagsAsResourceId`, `tab_<i>`, `primary_list`, a
   row tag for the deep stack) and a dev-flavour launch hook for `perf.fakeSession`/guest onboarding, build
   `devBenchmarkRelease`, then measure with the generator's `perf.sh` run from the integration checkout
   (`$R/templates/android/tools/perf/perf.sh --package <PeriFlow dev id> --variant devBenchmarkRelease`; it is not
   copied into PeriFlow) three runs each: `tabs pushpop pushpop_gesture rapid_back scroll_root idle coldstart
   coldstart_installed meminfo`, plus idle at a non-Today tab. Save to `$P/before/`.
2. **Navigation** (port from the generator, adapting packages): KeptTabs v2 (only the active tab measured,
   `LocalTabVisible`, trimmed on session reset; N5, G8), one host call site with one stage (N6), BackGate with
   coalescing instead of `BackHold`'s replay (N3; also the ≈ 360 ms critically damped screen spring), slide-only
   transitions with the draw-phase scrim and edge shadow (N4), linear predictive pop including modal (N8). Keep
   PeriFlow's product choice of hiding the bar on pushed screens, but implement it with `BarAnchor` so the bar stays
   composed and travels with the root screen (N1, N2, G2, G3: no `AnimatedVisibility`, no fade over the backdrop).
3. **Sheets**: the generator's `AppSheetState` (idempotent dismiss, `MutatorMutex`, measured once, footer re-placed,
   rubber band) and `SheetScene` (Back disabled while dismissing) replace `AppDetentSheet`'s defects (N9, N10).
4. **Insets**: `LocalTopBarInset`/`LocalBottomBarInset` become the generator's `ChromeInsets` holder written with
   settled heights (N7); the FAB slot reads the bottom inset (N11).
5. **Glass**: replace `GlassBottomBar` + `GlassRail` with the generator's `LiquidTabs(orientation)` (G15), the drawn
   glass node with cached shadow (G9, G10), `SceneBackdrop` recorded once (G14), the lens only while pressed or dragged
   and no press scale on the bar body (G1), static effects and the per-event coroutine fixes (G6, G13), the quality
   tiers with the FrameMetrics verdict and a "Reduce transparency" setting (G17), scroll-edge fade on every API (G11),
   frosted without sampling (G12), dead glass code removed (G16).
6. **PeriFlow-specific costs**: the stage aura removed on phones and the window background not drawn behind an opaque
   scene (G4); the aura crossfades between two cached pictures instead of repainting a bitmap per frame (G5); the voice
   orb on layer properties with cached brushes, paused when `LocalTabVisible` is false or reduce motion is on, at the
   normal frame rate (G7).
7. **Devtools badge**: the same fix as WP06 (live-state accumulation, clamp at placement, layout-phase offset, 48 dp
   target, Back inside the panel).
8. **Play update**: a downloaded update asks with a "Restart" action instead of restarting under the user; the update
   check runs once per process (template-infra §14; PeriFlow already remembers a dismissed version).
9. **Comments**: when porting, keep the why in one sentence and drop history and measurement anecdotes
   (periflow-learnings §6).
10. **Tests**: port `KeptTabsTest`, `BackGateTest`, `RapidBackTest` and the sheet double-dismiss test; keep PeriFlow's
    existing tests green (`KeptTabsBackTest`, `BackHoldTest` replaced by the BackGate tests with the reason in the
    commit message).
11. **Measure again** (same scenarios, three runs, `$P/after/`), iterate until the gates below hold: at most three
    measure → fix iterations per failing gate, then escalate with numbers and a trace (B.1).
12. **Commit** in small steps with messages that explain why; stage explicit paths.

## Acceptance

PeriFlow uses glass, so its gates are the §2 glass `Live` column, written as a `periflow` column in
`$OV/perf/WP11/gates.toml` (outside both repositories; `perf.sh --gates <file>` reads it): Today scroll janky ≤ 2.0 % and GPU p90 ≤ 8 ms (from 6.8 % / 20 ms); tab switch ≤ 2.5 % (from 4.0 %)
with first frame ≤ 10 / ≤ 20 ms; push/pop key ≤ 3.0 % / p99 ≤ 30 ms and gesture ≤ 3.0 % (from 6.1–6.5 %); pop first
frame ≤ 10 / ≤ 20 ms; rapid Back: no crash, correct final screen, no blank frame; idle at a non-Today tab 0 frames and
at Today GPU p90 ≤ 5 ms; cold start ≤ 400 ms speed-profile and ≤ 420 ms as installed (from 469 / 560 ms); PSS ≤ 90 MB
(from 108 MB). A gate may be relaxed only if the handoff proves, with numbers, a cost that exists only in PeriFlow
(for example the aura) and shows what removing it would do; the orchestrator then asks the user.

`$O/accept.sh` (`set -euo pipefail`, in the background, ends with `ACCEPT OK`):

```bash
#!/usr/bin/env bash
set -euo pipefail

  :core:designsystem:testDebugUnitTest :app:testDevDebugUnitTest --console=plain

  --gates $P/gates.toml --runs 3 --out $P/after --gate periflow tabs pushpop pushpop_gesture rapid_back scroll_root idle coldstart meminfo coldstart_installed
test -z "$(git -C $OV/wt/WP11 rev-parse --abbrev-ref --symbolic-full-name '@{u}' 2>/dev/null)"   # no upstream
test "$(git -C $OV/wt/WP11 rev-parse --abbrev-ref HEAD)" = "overhaul/smooth-glass"
test -z "$(git -C $OV/wt/WP11 diff --name-only main..HEAD -- . ':!periflow-android')"          # nothing outside periflow-android
test -n "$(git -C $OV/wt/WP11 log --oneline main..HEAD)"

```
