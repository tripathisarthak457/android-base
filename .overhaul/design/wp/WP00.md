# WP00 Repository move and seeds (orchestrator, wave 0)

Run by the orchestrator before any other package branches. About 30 minutes. Everything else branches from the
commit this produces, so it must be small, mechanical and verified.

## Why

The overhaul adds two templates. `template/` becomes `templates/android/` so the three sit side by side
(MASTER-PLAN A1.1). Doing the move first, alone, means no package ever has to merge a rename against its own edits.
Two packages (WP03 design system, WP04 navigation) start in parallel and both need the content-under-chrome contract
(per-screen top inset, shell-wide bottom inset) and the hidden-content signal (`LocalTabVisible`), so both are seeded
here verbatim (MASTER-PLAN A3.5). The insets are split by owner on purpose: one shared `top` value would be written by
two screens in alternation during every push and pop.

## Before anything: kickoff approvals

Ask the user once for the batch in MASTER-PLAN B.5 ("Kickoff") and record the answers in `$OV/PROGRESS.md`. Ask the
early CI question there too (may package branches be pushed to a private CI run).

## Owned paths

The move of `template/` → `templates/android/`; path references in `generator/**`, `tools/**`, `Dockerfile`,
`.dockerignore`, `.vercelignore`, `.github/workflows/ci.yml`, `AGENTS.md`, `README.md`, `web/README.md`; the two
JVM-argument lines in `templates/android/gradle.properties`;
`templates/android/core/designsystem/src/main/kotlin/com/base/app/core/designsystem/foundation/Chrome.kt` (new).

   cd $R

   `Dockerfile` (`COPY template …`), ignore files, the CI workflow, and path mentions in the three Markdown files.
   Change paths only; do not reword docs (WP12 rewrites them).
4. Seed `templates/android/core/designsystem/src/main/kotlin/com/base/app/core/designsystem/foundation/Chrome.kt`:
   ```kotlin
   package com.base.app.core.designsystem.foundation

   import androidx.compose.foundation.layout.PaddingValues
   import androidx.compose.foundation.layout.calculateEndPadding
   import androidx.compose.foundation.layout.calculateStartPadding
   import androidx.compose.runtime.Composable
   import androidx.compose.runtime.Stable
   import androidx.compose.runtime.compositionLocalOf
   import androidx.compose.runtime.getValue
   import androidx.compose.runtime.mutableStateOf
   import androidx.compose.runtime.setValue
   import androidx.compose.runtime.staticCompositionLocalOf
   import androidx.compose.ui.platform.LocalLayoutDirection
   import androidx.compose.ui.unit.Dp
   import androidx.compose.ui.unit.dp

   /**
    * Height of floating chrome over one edge. The holder never changes; its value is snapshot state written with
    * settled heights, so a change recomposes only the code that reads it rather than every screen below the provider.
    */
   @Stable
   class ChromeInset {
       var value: Dp by mutableStateOf(0.dp)
   }

   /**
    * Chrome over the bottom edge: the tab bar, its accessory, or the keyboard when it hides the bar. One holder per
    * window, provided by AppTheme and written only by the shell, so a toast host above the shell can read it too.
    */
   val LocalBottomChrome = staticCompositionLocalOf { ChromeInset() }

   /**
    * Chrome over the top edge of the current screen: its top bar. Every AppScaffold provides its own holder, so two
    * screens composed during a push or pop never write the same state.
    */
   val LocalTopChrome = staticCompositionLocalOf { ChromeInset() }

   /**
    * False inside a kept tab or a covered entry that is not on screen. Ambient animations (shimmer, spinners, anything
    * infinite) stop while it is false, so hidden content costs nothing per frame.
    */
   val LocalTabVisible = compositionLocalOf { true }

   /** [base] plus the chrome at both ends, for a scrolling container's contentPadding. */
   @Composable
   fun chromeContentPadding(base: PaddingValues = PaddingValues(0.dp)): PaddingValues {
       val top = LocalTopChrome.current
       val bottom = LocalBottomChrome.current
       val direction = LocalLayoutDirection.current
       return PaddingValues(
           start = base.calculateStartPadding(direction),
           top = base.calculateTopPadding() + top.value,
           end = base.calculateEndPadding(direction),
           bottom = base.calculateBottomPadding() + bottom.value,
       )
   }
   ```
4a. Set the Gradle memory once, so every worktree's builds reuse one daemon (identical JVM arguments) and the 15 GB
   machine is not exhausted by idle daemons (audit template-build D10). In `templates/android/gradle.properties`
   replace the two existing lines (the build cache and configuration cache are already on; leave them):
   ```properties
   org.gradle.jvmargs=-Xmx4g -XX:MaxMetaspaceSize=1g -XX:+UseParallelGC -Dfile.encoding=UTF-8
   kotlin.daemon.jvmargs=-Xmx2g -XX:+UseParallelGC
   ```
   The multiplatform template (WP07) uses the same two lines. Stop the old daemons once:
   `cd $R/templates/android && $L gradle ./gradlew --stop`.
5. Verify with `$O/accept.sh` (run in the background, log to `$O/logs/accept.log`):
   ```bash
   #!/usr/bin/env bash
   set -euo pipefail
   export ANDROID_HOME=$HOME/Android/Sdk
   R=/home/crazyhusir/Documents/projects/tools/android-base
   OV=/home/crazyhusir/Documents/projects/tools/.overhaul; L=$OV/bin/locked; O=$OV/out/WP00
   cd $R/generator && python3 -m unittest discover -s tests -t .
   python3 create_project.py --spec tests/spec_full.json    --out $O/after-full    --no-zip --force
   python3 create_project.py --spec tests/spec_minimal.json --out $O/after-minimal --no-zip --force
   for v in full minimal; do
     # the only allowed differences: the commit stamp, the two JVM lines, and the seeded file
     diff -r -x generator-spec.json -x gradle.properties -x Chrome.kt $O/before-$v $O/after-$v
     diff <(grep -v -E '^(org\.gradle\.jvmargs|kotlin\.daemon\.jvmargs)=' $O/before-$v/gradle.properties) \
          <(grep -v -E '^(org\.gradle\.jvmargs|kotlin\.daemon\.jvmargs)=' $O/after-$v/gradle.properties)
     grep -qx 'org.gradle.jvmargs=-Xmx4g -XX:MaxMetaspaceSize=1g -XX:+UseParallelGC -Dfile.encoding=UTF-8' $O/after-$v/gradle.properties
     grep -qx 'kotlin.daemon.jvmargs=-Xmx2g -XX:+UseParallelGC' $O/after-$v/gradle.properties
     test -n "$(find $O/after-$v -name Chrome.kt -path '*foundation*')"
   done
   cd $R/templates/android && $L gradle ./gradlew :core:designsystem:compileDebugKotlin :app:assembleDevDebug --console=plain   # no OOM at 4 GB
   echo ACCEPT OK
   ```
6. Commit with a message that explains why (three templates side by side; the chrome contract shared by two
   packages starting in parallel), then create the first worktrees for wave 0:
   ```bash
   for wp in WP01 WP02 WP03 WP04 WP09; do git -C $R worktree add $OV/wt/$wp -b wp/$wp overhaul/multiplatform-v2; done
   ```
