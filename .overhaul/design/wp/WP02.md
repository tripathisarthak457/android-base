# WP02 Android architecture, MVI and build

Waves 0 → 2, three milestones with separate merges. Kotlin, Gradle (heavy), Python (generator Android target, from M2).
Lock budget: Gradle about 6.5 h over the three milestones (M1 2.0, M2 3.0, M3 1.5), adb 0.3 h (M3 screenshots).

## Why

The template's MVI base holds every event behind a suspending queue, so Back, typing and Retry wait for network I/O
(audit features-data F1). `:core:common` is Android-bound, which blocks sharing with Compose Multiplatform (F23).
Modules have no public surface: DTOs and implementations are public, cross-feature navigation has no home (PeriFlow put
keys in core, VitFleet built a 292-line god module), and nothing scales to many teams without over-engineering small
apps (F8, F9, F13). The build adds dependencies, plugins and test plumbing that modules never use, and ships 83
unused locales, five near-identical APKs and LICENSE files (audit template-build C, D). The scaffolder emits code that
crashes at runtime (F2, F3). The forbidden patterns that make apps janky are only written down, never enforced.

## Milestone M1: structure and MVI (wave 0; merge early)

acceptance passes.

1. **`:core:common` becomes pure Kotlin with no DI** (`<pkg>.jvm.library`; no `javax.inject`, no `dagger`, no
   `java.*` imports; MASTER-PLAN A2.2). Contents:
   - `result/AppResult.kt`, `result/AppError.kt` exactly as A6.2, with `map`, `onSuccess`, `onFailure`,
     `errorOrNull` (only the helpers something uses).
   - `LoadState.kt` (`Error` carries `AppError`).
   - `coroutines/AppDispatchers.kt` (`class AppDispatchers(val io: CoroutineDispatcher, val default:
     CoroutineDispatcher, val main: CoroutineDispatcher)`) and `coroutines/ApplicationScope.kt`
     (`class ApplicationScope(scope: CoroutineScope) : CoroutineScope by scope`), replacing the `@IoDispatcher`,
     `@DefaultDispatcher` and `@ApplicationScope` qualifiers of `:core:coroutines` (annotations from `javax.inject` do
     not exist in `commonMain`). Hilt provides both in `app/src/main/kotlin/**/di/CoroutinesModule.kt`, where the
     application scope gets a logging `CoroutineExceptionHandler`. Migrate every injection site
     (`@IoDispatcher private val io` → `private val dispatchers: AppDispatchers`).
   - `time/AppClock.kt` on `kotlin.time` (opt in where the pinned Kotlin still marks it experimental).
   - `navigation/AppNavKey.kt`: `interface AppNavKey` (moved out of `:core:navigation`, keep its KDoc) and
     `interface FullScreenKey : AppNavKey` (new marker: the destination hides the tab bar, A3.5). In
     `core/navigation/.../AppNavKey.kt` delete only the interface declaration and leave `NavTransitionStyle` (WP04's).
   - `validation/` rules returning error codes (no `R.string`), `log/AppLogger.kt` (interface + `Log` facade; the
     Android backend is installed by the app), `network/NetworkMonitor.kt` (interface only; move the existing
     implementation unchanged into `:core:network` so it compiles: WP06 rewrites it), `session/` interfaces:
     `SessionController` exposes `state: StateFlow<SessionState>` with `SignedOut` and `SignedIn(generation: Int)`
     (WP04's shell keys kept tabs and stacks on the generation; adapt today's implementation to it, WP06 rewrites
     it), plus `SessionScopedStore`.
   - Delete `core/common/src/main/AndroidManifest.xml` (the permission moves with the monitor) and its `res/`
     (strings move to `:core:ui`; move their translations too: in `generator/translations/<lang>.json` before WP01
     merges, in the per-module files after).
2. **`:core:mvi`** (new Android library, no Compose): `MviViewModel` exactly as A6.1 (non-suspending `handleEvent`,
   `launchLatest(key, debounce)`, `launchExclusive(key)`, `cancel(key)`, `observe(flow, reduce)` collecting only while
   `state` has subscribers with a 5 s grace, `onUnexpected`), `UiState`/`UiEvent`/`UiEffect`, `UiMessage` with a
   unique id, `UiText`. The jobs map is touched only on the main thread: launch through `viewModelScope` (Main.immediate)
   and remove a job in its own completion only if it is still the mapped one.
3. **Delete `:core:model`** (nothing imports it) and **`:core:coroutines`**; remove them from settings, conventions and
   every build file.
4. **`api/` packages and shared keys** (A2.3, A2.4). In every feature module move the navigation keys into
   `<pkg>.feature.<name>.api`; in every data module move the repository interface and domain models into
   `<pkg>.data.<name>.api` (models under `api/model/` when there are several). Make DTOs, mappers,
   `Default*Repository` and everything else `internal`. A key that another feature opens moves to
   `core/navigation/src/main/kotlin/<pkg path>/feature/<owner>/api/` with the owner's package (no import changes);
   keys carry only primitives, `@Serializable` value classes from the same package, or `:core:common` types. Fix
   imports everywhere (including `:app`).
5. **Migrate every ViewModel** (sample list/detail, auth sign-in/sign-up/reset, settings, onboarding, profile, search
   and its result screen, feed, licences): `handleEvent` not suspending; I/O through `launchLatest` (loads, search,
   refresh) or `launchExclusive` (submits); initial load from an `Appeared` event sent by the Route from a
   `LaunchedEffect(Unit)`; repository flows through `observe`; navigation effects emitted before any persistence
   write (F18). **Text input** follows A6.1 exactly: each field is a `TextFieldState` owned by the ViewModel, created
