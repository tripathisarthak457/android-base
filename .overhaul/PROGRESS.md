## Audit headlines

- **Tab switches.** Each switch rebuilds the whole incoming tab: first frame 21–52 ms, 1–5 frames dropped. The two tabs cross-fade with both visible at once.
- **Bottom bar.** It moves on its own vertical spring, out of step with the screens. It also reserves an empty strip, so root screens are cut off above it.
- **Fast back presses.** A back press during a running push or pop re-targets that animation, and nothing guards against it.
- **Ripple.** A grey 9% overlay is drawn on every touchable. Filled buttons stack three press effects at once.
- **API log badge.** It can't be dragged, because the drag reads a stale position. Measured on the Redmi: a 503×1038 px swipe moved it 7×14 px.
- **PeriFlow glass.** It is limited by the GPU: 6.8% janky frames while scrolling. Each tab tap re-renders about 8 offscreen passes for half a second, and the bar is rebuilt on every return to a tab's first screen.
- **Generator bugs:**
  - Names are renamed twice, so `com.base.apple` becomes `com.base.applele`.
  - `--icon` writes broken XML.
  - Specs like `["auth"]` alone produce an app that crashes on launch.
  - Signing breaks when the store and key passwords differ.
- **Sign-in token leak.** After sign-out, the network client keeps the old user's sign-in token, so the next user's requests can go out as them.
- **Push.** Turning on push pulls in all of Firebase, about 0.7 MB of dex for analytics alone. Notifications are never shown on Android 13+.
- **Speed checks.** Debug builds are 10× jankier than release builds, so smoothness is only measured on release or benchmark builds.
