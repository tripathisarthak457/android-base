**What a selection does now (Live tier, motion not reduced).** A tap, Back to another tab's stack, a deep link or a
restore all go through `LiquidLens.moveTo`, one spring (`MoveSpring`, critically damped, stiffness 1000). From that
spring's own velocity the lens derives `travel` = `FastOutSlowIn(|v| / 4 tabs/s)`, clamped to 0..1 and cut to 0 below
0.01, so it ends about 80 ms before the spring settles (adjacent tab: full lift to ~110 ms, flat by ~210 ms of a
~290 ms move; four tabs: flat by ~260 ms of ~340 ms). `lift = max(press, travel)` drives, in draw and in the lens's own
layer block only: the swell (to 1.2×), the stretch along the path (up to 1.25× along, 0.8× across), the magnification
(to 1.2× about the lens's middle) and the fade of the clear lens in and of the frosted idle tint out. While lifted,
the lens samples the scene recorded once **and the accent tab row recorded once**, both drawn by reference into the
lens's own Kyant effect layer, so the lens's refraction bends the labels at its rim (the look of the old build) and
the page behind it. The flat accent copy clipped to the lens fades to `1 - lift` (`ModulateAlpha`, no offscreen).
At rest the lens samples nothing, as before.

**G1 kept.** No bar-body `layerBlock`; the bar body, glow, tab scale and lean read only `pressProgress`/`barLean`,
which a selection never changes (unit-tested with a snapshot observer, below). No dispersion, no inner shadow
anywhere. The tab row is still recorded once (now through Kyant's `layerBackdrop`, which also gives the lens its
position); the bar's glass is not re-rendered by a tap. A drag keeps the full press: swell springs, glow, tab scale,
lean, and now also the rim-bent tabs and magnification, as Kyant's original did.

**Decisions (the user asked not to be asked).**
- Kept run 5's velocity-derived lift (no new animation, no coroutine). Animatable's velocity is not snapshot state, so
  `velocity` reads `settled.value` first; that is what makes the layer and draw blocks follow the speed.
- The lift is gated on the lens actually bending the scene (`scene != null && quality.refracts`), not on the tier
  alone: a lifted lens with no recorded scene only lost its tint. `liftOnTravel(bendsScene, reduceMotion)`.
- Below Live, a slide no longer re-runs the lens's layer block per frame (the stretch now reads the speed only when
  lifted); run 5 had introduced that per-frame re-run on every tier.
- The travel swell is a floor only while travelling, so a dropped drag keeps its jelly undershoot (run 5 clipped it).
- Added the tab row to the lens's sampling after comparing strips: over PeriFlow's flat pink page the scene alone
  refracts almost nothing visible, so run 5's lens read as a magnifier with labels clipped flat at its edge.
- Onset is not smoothed: a critically damped spring reaches 4 tabs/s inside its first 8 ms frame, so the lens lifts
  in one frame and calms over the last ~100 ms. That matches iOS's "instant flex"; smoothing it would need either a
  second animation or the start position, which the brief ruled out.

## Rules and gotchas the docs must state

Learned on PeriFlow; each one is in the commits above with its reason.

1. **Never hide floating glass chrome with `AnimatedVisibility` or a fade.** Hiding disposes it, so the next show
   builds its backdrop layer and AGSL shaders in the first frame of a pop; any alpha < 1 above a `drawBackdrop`
   renders the whole chrome offscreen every frame. Keep it composed, move it on a layer, set alpha 0 only on the
   frame it is fully hidden (HWUI then skips it), and clear its semantics while hidden.
2. **A tap on a glass tab moves the lens and nothing else.** Swell, glow, refraction and scale are for a held or
   dragged lens. A tap that "presses" the bar re-renders blur, lens, highlight and shadow for about half a second.
3. **Glass is see-through, so its shadow must be outside-only.** Platform elevation and `dropShadow` darken the
   body. Bake an outer-only shadow once per (size, shape, density) into an `Alpha8` mask and draw that image; never
   build a `Path`, `Paint` or `BlurMaskFilter` per draw.
4. **Entrance fades on items with outer shadows use `CompositingStrategy.ModulateAlpha`.** The default offscreen
   layer clips the shadow at the bounds ("square shadow corners") and costs a buffer.
5. **Scroll-edge fades: an offscreen `GraphicsLayer` masked with a `DstIn` gradient** works on every API level at
   the same cost; `RenderEffect` blend effects need API 31.
6. **The frosted tier must not call `drawBackdrop` at all.** Below API 31 Kyant's effects are no-ops, but the scene
   is still recorded and replayed sharply under the tint on every scroll frame.
7. **Kyant `drawBackdrop` allocates its chain per call.** Keep effect lambdas as top-level vals, remember the
   modifier keyed by scene, tier and colours, and pass the list of tabs as a remembered list so the bar skips.
8. **Record a row once and draw it twice.** The accent copy of the tabs under the lens is the row's recorded
   `GraphicsLayer` drawn with a tint, clipped to the lens outline; a second composed row costs a full composition,
   measure and an offscreen colour-filter layer.
9. **Glass quality is a policy, not a device check.** Inputs: API level (31 blur, 33 AGSL lens), low RAM, battery
   saver, thermal status, a measured GPU verdict and the person's Reduce transparency. Measured signals only lower
   the tier for the rest of the session; the verdict is stored per `Build.FINGERPRINT` and install time. Do not use
   the media performance class: most mid-range phones declare none.
10. **Measure glass with the tier pinned** (`--extra glass.quality=Live` in PeriFlow's dev flavour), and also
    unpinned, which is what users get: an unpinned run can frost itself partway through and pass by removing glass.
11. **Drop the window background once every screen paints its own** (after the first frame, so the splash still
    covers launch). A stage background behind a full-window navigation host is pure overdraw: HWUI does no
    occlusion culling.
12. **Never animate the colours of a painted background.** Crossfade two cached pictures instead; animating inputs
    into a bitmap paints on the main thread every frame (and on every cold start when the first value is a
    placeholder).
13. **Ambient motion (orbs, glows) runs on layer properties with brushes built in `drawWithCache`, asks for
    `FrameRateCategory.Normal`, winds down after a few seconds, and pauses when `LocalTabVisible` is false or reduce
    motion is on.** PeriFlow's orb kept the window at the display rate on every tab: 606–632 frames in 5 idle
    seconds (before/ idle).
14. **Gesture state never comes from a value captured when the gesture started.** `pointerInput` outlives
    recompositions; accumulate drags in state read at placement, and read sizes and layout direction through state.
15. **Never call Play's `completeUpdate()` without the person's "Restart".** Check for updates once per process, and
    count a review-prompt launch once per process, not per resume.
